# build-verification/disassembly/

Generated by `verify-isa.sh` (called automatically at the end of
`./build.sh <variant>`; run manually as `./verify-isa.sh <build-dir>`).

Contents after a build:

- `isa-verify-report.txt` — PASS/FAIL verdict per required kernel
  (`q4_0_breit` n=1/4/8, `q5_K_breit`, `q6_K_breit`): gfx906 ISA present,
  `private_segment_fixed_size` (scratch) = 0 for defaults, cross-checked
  against `../mmvq-gfx906-kernel-resources.tsv`.
- `<kernel>/disassembly.txt` — `roc-objdump`/`llvm-objdump -d` output for each
  required kernel symbol.
- `.code-objects/` — gfx906 ELF code objects extracted from the build tree.
- `INDEX.txt` — pointer file with timestamp.

Generated dumps are not committed to git (see `.gitignore`); regenerate with
`./verify-isa.sh <build-dir>`.

No performance interpretation is made from these artifacts — they are
structural ISA evidence only (speed requires the MI50, see BUILD-VERIFICATION.md).
